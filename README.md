# REST API Workspace

Small collection of Python projects and examples.

## Folders

- API: Example login API code.
- Database: Database models and setup.
- migration/migrations: Alembic migration templates and revisions.
- proj: Small Python demos.
- task manager: Full task manager app with API and docs.

## Quick Start

1. Open a folder you want to run.
2. Install its requirements.
3. Run the app entrypoint for that folder.
